Then untrack junk:

git rm -r --cached dist tmp server.pid "*.zip" "package.json.backup" "package.json.working" "replit.md.backup"
git add .gitignore
git commit -m "chore: clean repo + add .gitignore"

B. Standardize to TypeScript + ESM

Keep vite.config.ts, delete vite.config.js:

git rm vite.config.js
git commit -m "chore: drop duplicate vite.config.js; standardize on TS"


(If any server files use CJS: convert or run Node with "type": "module" and TS build output set to ESM.)

C. Introduce npm workspaces

package.json (root)

{
  "private": true,
  "workspaces": ["client", "server", "shared"],
  "type": "module",
  "engines": { "node": ">=20 <21" },
  "scripts": {
    "build": "npm run -ws build",
    "dev": "npm run -w server dev & npm run -w client dev",
    "lint": "npm run -ws lint",
    "typecheck": "npm run -ws typecheck",
    "test": "npm run -ws test"
  }
}

D. Add minimal CI

.github/workflows/ci.yml

name: CI
on:
  push: { branches: [ main ] }
  pull_request:
jobs:
  build-test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: '20', cache: 'npm' }
      - run: npm ci
      - run: npm run typecheck || true
      - run: npm run lint || true
      - run: npm run build
